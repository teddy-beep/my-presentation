1. System Overview

What is SiketPlus?

A comprehensive share management system designed for companies to manage:

  • Shareholder registration and management
  • Share issuance and transfers
  • Dividend distribution
  • Meeting management and voting
  • Certificate generation
  • Mobile app integration

Key Features

Shareholder Management

Individual and corporate registration with multi-language support (English & Amharic)

Share Operations

Share issuance, transfers, payment tracking, and tax calculation

Dividend Management

Dividend declaration, tax calculation, multiple payment methods

Meeting & Voting

AGM/EGM management, real-time voting, Power of Attorney support

Certificate System

PDF generation, Ethiopian date support, customizable design

Mobile Integration

RESTful API, Flutter web app, native mobile app ready

3. Architecture & Design

System Architecture

Web Application
(Admin/User/Reports)
↓
Laravel Layer
(Controllers/Models/Services)
↓
API Layer (v1)
(Auth/Shareholder/Voting)
↓
Database Layer
(SQLite/Cache/Queue)

Design Patterns

  • MVC Pattern - Models, Views, Controllers
  • Service Layer - Integration, Backup, Permission services
  • Repository Pattern - Eloquent models with relationships
  • Job Queue - Background job processing

6. API Architecture

API Overview

Base URL: /api/v1/

Authentication

Token-based, Password-based, OTP verification

Shareholder Operations

Verify, profile, transactions, bank details

Meeting & Voting

Active meeting, cast vote, live results

Dividends

Summary, transactions

Certificates & Transfers

Request certificates, request transfers

Configuration

App config, announcements, quorum stats

Key API Endpoints

Method Endpoint Description
POST /shareholders/register Register mobile user
POST /shareholders/login Login shareholder
GET /shareholders/verify/{id} Verify shareholder
GET /meetings/active Get active meeting
POST /votes/cast Cast vote
GET /votes/live-results/{id} Get live results
GET /dividends/summary/{id} Get dividend summary
POST /shareholders/certificate-requests Request certificate
